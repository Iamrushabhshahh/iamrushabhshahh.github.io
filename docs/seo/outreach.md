## Syndication with a canonical URL

Semrush's backlink gap report specifically shows Medium and GitBook as
places competitors get links from that this site doesn't. A canonical URL
tag is what makes syndication safe for SEO - it tells Google the original
lives at rushabhshah.dev, so the mirror doesn't compete with or dilute it.

- [ ] Medium: cross-post with `<link rel="canonical">` back to the original
      (Medium's own "Import a story" tool sets this automatically)
- [ ] dev.to: cross-post using its `canonical_url` front-matter field
- [ ] Hashnode: cross-post using its canonical URL field at import

Good first candidates: the CKA/CKAD/CKS guides and the Kubestronaut cost
post - already written, already ranking, and already proven useful.

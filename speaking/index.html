Talks I can give

Each one has been given or accepted somewhere already, and each can be cut to a lightning talk or grown into a hands-on workshop.

  • Kubernetes disaster recovery that survives a real restore

    What Git can and cannot bring back, and how Flux and Velero cover the rest. Live failure, live recovery.

    Coming up at FluxCon North America 2026

  • Migrating to Prometheus native histograms

    Running classic and native histograms side by side, proving the queries agree, and the dashboards that break on the way.

    As given at PromCon EU 2026

  • Observability for AI agents

    Tracing every model turn and tool call with OpenTelemetry so an agent's decisions can be debugged like any other service.

    As given at Cloud Native Vadodara September Meetup

  • Containers for agents

    Compose for agents, MCP and sandboxed runtimes, shown as a working demo rather than a roadmap slide.

    As given at Docker Ahmedabad Meetup

  • Supply chain evidence an auditor can trust

    Why a mutable tag is not an approval, and what to enforce in policy instead.

    Coming up at Open Compliance Summit 2026

  • Cloud native from zero, for students

    One app from laptop to container to Kubernetes, with the failure each step fixes shown live.

    As given at Cloudscape: Kickstart with Cloud Native

  • Observability from zero, for beginners

    Grafana or OpenSearch, from an empty install to a dashboard people actually use, in one session.

    As given at Cloud Native Ahmedabad x Grafana Ahmedabad cross meetup
